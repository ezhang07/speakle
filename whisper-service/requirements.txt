# FULLY PINNED, including transitive dependencies. Do not loosen these.
#
# Why: `docker compose --build` is mandatory on every backend deploy, so an
# unpinned file re-resolves the whole dependency tree on each one. That broke
# production once already: pip pulled av 19.0.0, which removed the
# `metadata_errors` kwarg that faster-whisper's decode_audio still passes to
# av.open(). The container started fine and the model loaded fine — it failed
# at request time with a TypeError, so every transcription job errored while
# the service looked healthy.
#
# `av` is the reason transitive deps are pinned too: it is NOT a direct
# dependency, it arrives via faster-whisper, which declares it with no upper
# bound. Pinning only the four direct packages would not have prevented this.
#
# To regenerate after an intentional upgrade: rebuild, run a real transcription
# to confirm it works, then `docker exec speakle-whisper-1 pip freeze`.
